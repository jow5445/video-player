# Video Player

A modern and responsive web-based video player built with HTML, CSS, and JavaScript. The application provides a clean interface for playing videos with essential playback controls and a smooth user experience.

## Features

- Play and pause videos
- Progress bar with seeking support
- Volume control
- Mute and unmute
- Fullscreen mode
- Display current playback time and total duration
- Responsive design
- Lightweight and fast
- No external frameworks required

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- HTML5 Video API

## Getting Started

Clone the repository:

```bash
git clone https://jow5445.github.io/video-player
```

Navigate to the project directory:

```bash
cd video-player
```

Open `index.html` in your preferred web browser.

## Customization

You can customize the player by:

- Replacing the default video file.
- Modifying the interface in `style.css`.
- Adding features such as playback speed controls, subtitles, keyboard shortcuts, or playlists.
- Changing the layout to match your own design.

## Browser Support

Compatible with modern browsers including:

- Mozilla Firefox
- Microsoft Edge
- Safari
